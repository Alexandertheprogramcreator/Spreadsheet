Export

  1. Click Download HTML file below. Your spreadsheet is saved as a web page with its colors, bold, italics and alignment.
  2. Open drive.google.com, choose New, then File upload, and select the downloaded file.
  3. Open the uploaded file in Drive and choose Open with,Google Docs.
  4. Google Docs converts it into a document with your table and formatting carried over. Use File, then Download or Share from there.
